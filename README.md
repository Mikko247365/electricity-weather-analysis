# Säätilan vaikutus sähkönkulutukseen Suomessa

Tässä projektissa analysoidaan lämpötilan vaikutusta sähkönkulutukseen Suomessa.

## Datalähteet

- Fingrid: sähkönkulutus Suomessa
- Ilmatieteen laitos: lämpötiladata

## Menetelmät

- Datan käsittely Pandasilla
- MW-arvojen muuntaminen päivittäiseksi GWh-kulutukseksi
- Sää- ja sähkönkulutusdatan yhdistäminen päivämäärän perusteella
- Visualisointi ja tilastollinen analyysi
